## 1. 优化基础包

### 1.1 需求描述（经过DeepSeek优化）
对 @framework/util 包进行优化，按领域划分，拆分为多个专注于特定领域的子包，项目结构示例：
```bash
framework/
├── pkg/               # 可供外部导入的公共库代码
│   ├── xstring/       # 字符串操作工具
│   │   ├── convert.go
│   │   ├── operation.go
│   │   ├── validator.go
│   │   └── xstring.go # 包文档文件
│   ├── xdate/         # 日期时间操作工具
│   │   ├── format.go
│   │   ├── calculate.go
│   │   └── xdate.go
│   ├── xslice/        # 泛型切片操作工具 (Go 1.18+)
│   │   └── xslice.go
│   ├── xmath/         # 数学和数字操作工具
│   │   ├── convert.go
│   │   ├── calculate.go
│   │   └── xmath.go
│   ├── xcrypto/       # 加密解密工具
│   └── xstruct/       # 结构体/Map等操作工具
```
需求如下：
- 优化 @framework/util 更改为 @framework/pkg ，拆分为多个子包。
- 将 @framework/util 包拆分为多个子包，按功能划分，如字符串处理、日期时间处理、切片操作、数学计算等。
- 每个子包应包含相关的工具函数，并提供清晰的文档说明。
- 更新项目中的导入路径，确保代码能够正确引用新的子包。
- 已知讲解：
    pkg/xstring/ (字符串工具包)
    pkg/xdate/ (日期时间工具包)
    pkg/xslice/ (切片工具包)
    pkg/xmath/ (数学工具包)
    pkg/xcrypto/ (加密解密工具包)
    pkg/xstruct/ (结构体工具包)
