## 路由注册多样性

分析 @framework/mvc/router/group.go 中的路由注册方式，主要有以下几种：

1. **基本路由注册**：GET(path string, handler core.HandlerFunc)
2. **简单路由**：如签名 type SimpleHandlerFunc = func(context.Context)
    实现 GETSimple(path string, handler core.SimpleHandlerFunc)
3. **直接路由**：如签名 type DirectHandlerFunc = func(context.Context, *RequestContext)
    实现 GETDirect(path string, handler core.DirectHandlerFunc)

要求：
- 实现的可能性，方法与签名合理命名
- 给出可执行的解决方案
- 如果可行，其他路由注册方式也一同解决
