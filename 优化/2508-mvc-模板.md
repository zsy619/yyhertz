     现状分析

     目前模板引擎的分隔符是在创建 TemplateEngine 时从配置文件读取的，并且在整个生命周期中是固定的。分隔符在以下地方被使用：
     1. 模板解析时通过 template.Delims(e.delimLeft, e.delimRight) 设置
     2. 每个模板文件加载时都会应用这些分隔符

     解决方案

     我将实现以下功能，让您能够在 view 层动态设置模板引擎的分隔符：

     1. 为 TemplateEngine 添加设置分隔符的方法

     // SetDelimiters 设置模板分隔符
     func (e *TemplateEngine) SetDelimiters(left, right string) error

     2. 为 TemplateManager 添加对应的方法

     // SetDelimiters 设置模板分隔符
     func (tm *TemplateManager) SetDelimiters(left, right string) error

     3. 添加便捷的全局函数

     // SetTemplateDelimiters 设置全局模板分隔符

     1. framework/mvc/view/engine.go
       - 添加 SetDelimiters 方法
       - 该方法需要：
           - 验证分隔符的有效性（避免三重花括号等问题）
         - 更新内部的 delimLeft 和 delimRight 字段
         - 清空模板缓存（因为需要用新分隔符重新解析）
         - 如果启用了热重载，重新加载所有模板
     2. framework/mvc/template/manager.go
       - 添加 SetDelimiters 方法，调用引擎的对应方法
       - 更新配置中的分隔符设置
