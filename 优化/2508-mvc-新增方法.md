
## 实现SetStaticPath

@framework/mvc 中需要实现 SetStaticPath 功能。
类似：SetStaticPath("public","/static")
第一个参数是静态文件目录（相对应用所在的目录）
第二数是路径，url 路径信息，可选，如果没有这设置为当前路径
并在 @framework/mvc/app.go 中实现 HertzApp 的静态方法

```claudeCode
     目标

     在 @framework/mvc 中实现 SetStaticPath 功能，支持用户需求的API规范，并在 app.go 中实现 HertzApp 的静态方法。

     实现方案

     1. 修改 core/app.go 中的 SetStaticPath 方法

     - 当前问题: 现有方法 SetStaticPath(path string) 只接受一个参数
     - 新的实现: 重写为 SetStaticPath(localDir string, urlPath ...string) 
     - 功能特性:
       - 第一个参数: 静态文件本地目录（相对应用所在目录）
       - 第二个参数: URL路径（可选），如果不提供则自动推导
       - 支持 SetStaticPath("public", "/static") 和 SetStaticPath("public") 两种调用方式

     2. 在 app.go 中添加 HertzApp 静态方法

     - 添加 SetStaticPath 静态方法，调用 HertzApp 实例的方法
     - 确保API一致性和易用性

     3. 实现细节

     core/app.go 中的方法更新:
     func (app *App) SetStaticPath(localDir string, urlPath ...string) {
         if app.StaticPaths == nil {
             app.StaticPaths = make(map[string]string)
         }
         
         // 确定URL路径
         var targetUrlPath string
         if len(urlPath) > 0 && urlPath[0] != "" {
             targetUrlPath = urlPath[0]
         } else {
             // 自动推导: "public" -> "/public", "assets" -> "/assets"
             targetUrlPath = "/" + strings.TrimLeft(localDir, "./")
         }
         
         // 确保URL路径以/开头
         if !strings.HasPrefix(targetUrlPath, "/") {
             targetUrlPath = "/" + targetUrlPath
         }
         
         // 注册静态路径
         app.StaticPaths[targetUrlPath] = localDir
         app.Static(targetUrlPath, localDir)
     }

     app.go 中的静态方法:
     // SetStaticPath 设置静态文件路径的静态方法
     func SetStaticPath(localDir string, urlPath ...string) {
         if HertzApp != nil {
             HertzApp.SetStaticPath(localDir, urlPath...)
         }
     }

     4. 测试更新

     - 更新 app_test.go 中的测试用例以验证新API功能
     - 测试单参数和双参数调用场景
     - 验证静态方法的正确性

     优势

     1. 向后兼容: 支持原有的单参数调用方式
     2. 灵活性: 支持自定义URL路径或自动推导
     3. 易用性: 提供HertzApp静态方法，简化使用
     4. 一致性: 与现有的代码风格和架构保持一致
```

## 实现 InsertFilter 方法

判断实现如下方法的可能性：
实现 InsertFilter(pattern string, position int, filter FilterFunc, params ...bool)方法：
- pattern 路由规则，可以根据一定的规则进行路由，如果你全匹配可以用 *
- position 执行 Filter 的地方，五个固定参数如下，分别表示不同的执行过程
    1. BeforeStatic 静态地址之前  　　
    2. BeforeRouter 寻找路由之前
    3. BeforeExec 找到路由之后，开始执行相应的 Controller 之前
    4. AfterExec 执行完 Controller 逻辑之后执行的过滤器
    5. FinishRouter 执行完逻辑之后执行的过滤器
- filter filter 函数 type FilterFunc func(*mvc.context.Context)
