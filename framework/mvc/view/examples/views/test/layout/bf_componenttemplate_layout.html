🏗️ 组件设计模式

🎯 原子组件

最小功能单元，如按钮、输入框、标签等基础UI元素。

示例: Button, Input, Label

🧩 分子组件

由多个原子组件组合而成，具有特定功能的组件单元。

示例: SearchBox, UserCard, NavMenu

🏢 组织组件

复杂的业务组件，由多个分子组件组合，实现完整功能。

示例: UserProfile, ProductList, Dashboard

📄 页面模板

最高级别的组件，整合所有组织组件，形成完整页面。

示例: HomePage, UserCenter, AdminPanel

💡 ComponentTemplate最佳实践

✅ 设计原则

单一职责

每个组件只负责一个具体的功能，保持简单和专注

接口清晰

定义清晰的数据接口，明确组件的输入和输出

可配置性

支持参数配置，提高组件的灵活性和复用性

❌ 常见陷阱

过度设计

避免为简单功能创建过于复杂的组件结构

紧耦合

组件之间应该松耦合，避免强依赖关系

状态混乱

避免在组件中混合业务逻辑和展示逻辑
