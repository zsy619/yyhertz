🔧 Include函数技术特点

📝 动态包含

可以动态地包含其他模板文件，支持运行时模板选择

📊 数据传递

支持向被包含的模板传递复杂数据结构，灵活性很高

🔄 嵌套支持

支持多层嵌套包含，可以构建复杂的模板层次结构

⚡ 高性能

优化的模板缓存机制，确保包含操作的高效执行

🔄 与其他模板函数的对比

Include vs TemplateInclude

功能完全相同，TemplateInclude是Include的别名

Include vs Partial

功能相似，Partial更侧重于部分模板的概念

Include vs Component

Component专注于组件化开发，Include更通用

💡 Include函数最佳实践

  • ✅ 合理组织模板结构

    将可重用的部分抽取到独立的模板文件中，提高代码复用性

  • ✅ 控制嵌套深度

    避免过深的嵌套包含，建议不超过3-4层，保证性能和可维护性

  • ✅ 合理使用数据传递

    传递必要的数据，避免传递过大的数据结构影响性能

  • ✅ 错误处理

    确保被包含的模板文件存在，并做好错误处理机制

💻 Include函数代码演示

控制器中的使用方法:
func (c *Controller) MyMethod() {
    // 设置数据
    c.SetData("User", map[string]any{
        "Name": "张三", 
        "Role": "开发工程师"
    })
    
    // 设置模板
    c.Layout = "main_layout.html"
    c.TplName = "user/profile.html"
    c.Render()
}
模板中的使用语法:
<!-- 基本包含 -->
{{`{{include "partials/header.html" .}}`}}

<!-- 传递特定数据 -->
{{`{{include "partials/user_card.html" .User}}`}}

<!-- 使用makedict传递多个参数 -->
{{`{{include "partials/form.html" (makedict "action" "/save" "method" "POST" "data" .FormData)}}`}}
