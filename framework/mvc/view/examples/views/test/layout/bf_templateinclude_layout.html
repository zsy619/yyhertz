🔧 TemplateInclude 技术实现原理

📝 别名机制

TemplateInclude在模板引擎内部直接映射到Include函数， 是纯粹的别名关系，没有额外的性能开销

⚡ 相同实现

底层使用完全相同的模板解析和渲染逻辑， 确保两种函数的行为完全一致

🔄 兼容性

为了兼容不同的开发习惯和框架迁移， 提供两种名称供选择使用

💡 使用建议

✅ 团队一致性

在同一个项目中统一使用一种函数名称，避免混用导致的混乱

📚 文档清晰

在项目文档中明确说明使用的是哪种函数名称，方便团队成员理解

🔧 迁移友好

从其他框架迁移时，可以选择更熟悉的函数名称，降低学习成本

💻 TemplateInclude函数代码演示

控制器中的使用方法:
func (c *Controller) MyMethod() {
    // 设置数据 - 与Include完全相同
    c.SetData("User", map[string]any{
        "Name": "张三", 
        "Role": "开发工程师",
        "Avatar": "/static/images/user.png"
    })
    
    // TemplateInclude与Include使用方式完全相同
    c.SetData("PageData", map[string]any{
        "Title": "页面标题",
        "Content": "页面内容"
    })
    
    // 设置模板
    c.Layout = "main_layout.html"
    c.TplName = "user/profile.html"
    c.Render()
}
